# 趣味小屋：功能规范

状态：用户已确认并授权实施。

## 目标与范围

中文内容空间：提供短笑话、可追溯的趣味知识，以及随机选择器、随机数和文字统计。用户无需登录。

首版提供首页、笑话角、冷知识、小工具、收藏视图，支持关键词搜索和内容类别切换。初始内容目标为 12 条原创笑话、12 条核实后的知识，全部功能内容完整可用。数量是本次建议的交付范围，不是现有库存。

不包含账号、云同步、投稿、评论、付费、后台、AI 生成、外部实时数据和离线缓存承诺。收藏仅限当前网站地址、浏览器及设备；清理浏览器数据会移除收藏。

## 用户故事

- P1：打开网站，读一条笑话或知识，再换一条。
- P1：输入候选项、整数范围或文字，得到可理解的工具结果。
- P2：按关键词或类别找内容，收藏后下次继续阅读。

## 行为规则

R01 内容具有稳定 ID、类型、标题、正文和标签；知识另有来源名称与链接。来源必须直接支持对应陈述。

R02 “换一条”在当前类别内随机切换，并排除当前条目；一条时保留内容并提示“只有这一条”；零条时显示空状态并禁用按钮。搜索结果采用列表浏览，不参与随机切换。

R03 搜索覆盖标题、正文、标签，去除查询首尾空白，拉丁字母不区分大小写。连续空白按一个空格处理；整段查询按子串匹配，不做分词。空查询展示当前类别全部内容；类别切换保留查询。收藏视图仅搜索已收藏内容。

R04 收藏以 ID 去重。取消立即移出收藏视图。使用带版本号的本地存储结构；未知 ID 忽略；损坏数据不使页面崩溃，并显示恢复提示。不静默覆盖无法识别的高版本数据。

R05 存储读写失败时仍允许本次会话内收藏，持续提示“当前收藏仅在本次打开期间保留”。只有持久化写入成功才能提示“已保存到此浏览器”。

R06 随机选择器一行一个选项，去首尾空白、移除空行及完全相同的重复项。至少两个有效选项；每项等概率。重复抽取允许出现相同结果。建议限制为 200 项、每项 100 个 Unicode 码点，超限拒绝并说明原因。

R07 随机数只接受十进制整数，范围为 -1,000,000,000 至 1,000,000,000，包含上下限；下限不能大于上限。相等时返回该数。空白、非整数、指数格式和超限输入均提示错误，不保留易被误认的新结果。

R08 字符数按 Unicode 码点计数，包含空白和换行，不等于视觉字形数量。去空白字符数移除 JavaScript Unicode 空白字符。CRLF、CR 统一为 LF；空文本为 0 行，非空文本为换行数加 1，末尾换行计入新行。输入时实时更新；最多 100,000 码点，超限提示并暂停统计，不静默截断。

R09 笑话和知识可复制正文；仅在剪贴板操作成功后提示成功，失败时提示手动选择复制。用户输入仅作文本处理，不作为 HTML 执行，不主动传出工具输入。

| AC-02 | 内容正常切换；多条不连续重复；零条与一条有明确状态 | 确定性逻辑测试及交互检查 |

| AC-05 | 收藏去重，刷新后保留，取消后刷新不恢复 | 浏览器持久化检查 |

| AC-08 | 保存、读取与复制失败有真实反馈，损坏数据不崩溃 | 故障注入测试及交互检查 |

## 完成定义

所有验收项有结果和证据；没有未解决的关键缺陷。未完成、未验证与环境限制必须分别记录。知识来源可追溯，但不承诺第三方链接始终在线。
